# Vue 前端视觉重设计

## 目标

在不改变实验室预约系统的接口、角色权限、数据含义和业务流程的前提下，重做 Vue 前端的视觉层级与响应式体验。新版应明显区别于当前深色工程后台风格，并适合长时间查看预约、排程和统计数据。

## 方案比较与选择

- 采用明亮现代工作台：雾灰背景、白色导航与圆角卡片、靛蓝主色、语义化状态色。信息层级清晰，改动范围适中，采用此方案。
- 保留原有深色侧栏并局部润色：成本最低，但视觉差异不足，不采用。
- 全深色科技风：展示效果强，但表格密集页面的阅读与状态识别较弱，不采用。

## 视觉系统

- 使用系统中文字体与 Segoe UI，不引入在线字体或新依赖。
- 页面采用浅灰蓝画布，卡片使用白色、细边框、14–20px 圆角和轻阴影；避免大面积渐变与装饰性图片。
- 靛蓝用于主要操作和当前导航；绿色仅用于开放、成功和正常使用；琥珀色用于等待；红色用于错误与危险操作。
- 统一页面标题、 eyebrow、面板、表单、按钮、表格、标签、分页、弹窗、空状态和加载状态。

## 页面与组件

### 应用框架

保留桌面侧栏与移动端抽屉行为。侧栏改为白色，品牌标识使用几何图形，导航采用分组圆角选中态；顶栏突出当前页面、终端入口和用户菜单。折叠与移动端逻辑继续使用现有状态。

### 工作台

保留真实 dashboard 数据、趋势图和按角色过滤的快捷入口。首屏增加简洁的欢迎区和主预约入口；实验室、今日预约、待排程、使用中作为核心指标，其余数据归入辅助指标。趋势图与快捷入口形成清晰的主次布局，空数据仍展示真实空状态。

### 登录与终端

登录页改为明亮双栏：左侧表达产品价值并展示纯 CSS 的预约时间板，右侧为独立登录卡片。保留开发账号填充、错误提示和终端入口。签到终端沿用相同品牌语言，不改变分步验证、倒计时和敏感信息清理。

### 业务组件

MetricCard 支持核心/辅助层级及语义色；SlotGrid 改用更清晰的可用、占用、选中与冲突状态；ReservationForm、AI 会话、统计图表和管理页面继承新变量与控件规范。所有现有 data-testid、表单字段、事件和接口载荷保持不变。

## 数据与异常

不重写数据获取和提交逻辑，不生成模拟业务数据。加载、空数据、接口错误、提交中、成功和危险操作继续使用现有条件渲染；仅更新呈现方式。图表更新配色、字体和间距，不改变数值计算。

## 响应式与可访问性

桌面使用 248px 侧栏，窄屏保留抽屉导航；指标网格逐级降为两列/单列，表格允许横向滚动。保留键盘焦点、时间格方向键、ARIA 标签和减少动态效果设置；交互控件维持可读对比度与足够点击面积。

## 验证

- 运行现有 Vitest 测试与 `npm run build`。
- 在浏览器实测登录页、终端页和可访问的业务页面；如后端可用则使用开发账号验证登录、导航、预约记录与新建预约弹窗。
- 检查桌面与移动视口，无横向页面溢出、文本遮挡或不可操作控件。

## 假设

- 用户要求的是完整视觉改版，而非新增业务功能。
- 当前工作目录不是 Git 仓库，因此只写入设计与实施文档，不创建提交。
- 自动模式下不等待风格选择，直接采用上述推荐方案。
