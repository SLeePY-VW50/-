# Cal.com DESIGN.md 模板优化设计

## 来源与安装

采用 `VoltAgent/awesome-design-md` 仓库的 `design-md/cal/DESIGN.md`，按仓库官方说明原样安装为项目根目录 `DESIGN.md`。该仓库不是 Skills CLI 技能，没有 `SKILL.md`，因此不通过 `npx skills add` 安装。

## 方案选择

- Cal.com：日历预约场景匹配，白色画布、近黑主操作、浅灰卡片和克制蓝色点缀，采用。
- SAP：企业目录风格清晰，但会引入更强的传统后台框架感，不采用。
- Linear：模板要求深色营销画布，不适合当前读表与预约操作，不采用。

## 优化范围

在上一版 Vue 工作台上做视觉收敛，不重写业务结构：

- 全局颜色切换到 Cal 的近黑 `#111111` 主操作、`#374151` 正文、`#6b7280` 次级文字、`#e5e7eb` 边线和 `#f5f5f5` 卡片；蓝色 `#3b82f6` 只用于少量链接和焦点。
- 标题保持 600 字重和负字距，使用模板许可的本地字体回退，不下载或新增字体依赖。
- 按钮与输入框采用 8px 圆角，内容卡片采用 12px，产品预览最多 16px；移除大面积紫色背景、重阴影和过度圆角。
- 导航使用白底、近黑选中态与浅灰分组；头像改为 36px 圆形。
- 工作台欢迎区改为白色产品区，保留真实日期、指标和预约入口；时间板作为真实产品界面碎片呈现。
- 登录页采用白底与浅灰产品卡片，主登录按钮改为近黑；时间格、分段控件和状态标签同步模板。
- 图表主色使用近黑，辅助色保留业务语义；状态成功、警告、错误仍使用模板语义色。

## 不变项

不修改接口、路由、权限、Pinia、表单校验、提交载荷、测试标识和真实数据。保留现有响应式导航、键盘操作、ARIA、加载与错误状态。模板中营销页专属的深色页脚不机械添加到后台页面。

## 验证

- 运行完整 Vitest 和 `npm run build`。
- 使用真实学生账号检查工作台、实验室、预约记录与新建预约弹窗。
- 检查登录页、终端页和移动导航；不提交预约或修改业务数据。
