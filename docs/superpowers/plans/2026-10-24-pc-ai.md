# 高校实验室电脑端与智能助手 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 依据 2026-10-24 修改后的设计说明书，在空目录中搭建可运行的 Vue 电脑端、Spring Boot 业务服务和独立 FastAPI 智能助手，不含小程序。

**Architecture:** `web/` 只通过 HTTP 调用后端；`server/` 是预约、权限、冲突和状态事实的唯一来源，使用 MySQL 8 事务与 Redis 锁；`ai-service/` 仅经 Java 白名单只读接口取数，Redis 保存短期历史，预约草稿仍由用户确认并进入原 Java 预约接口。排期算法为独立纯 Java 计算单元，主方案发布与对照实验隔离。

**Tech Stack:** JDK 21、Spring Boot 3.5.16、MyBatis-Plus 3.5.17、Spring Security JWT、MySQL 8.0.46、Redis 兼容服务、Vue 3 + TypeScript + Vite + Element Plus + Pinia + ECharts、Python 3.12 + FastAPI + LangChain、JUnit/Mockito、Vitest、Python unittest。

## 设计基线与取舍

1. 最新主说明书优先于早期定题说明：不引入 Python 遗传算法微服务；Python 只承担新版 AI 助手。
2. 电脑端包括学生/教师 Web、实验室管理员只读 Web、系统管理员 Web、独立签到页和 Web AI 助手；不创建小程序或微信接口。
3. 采用文档原生前后端方案，不采用 Electron 壳，也不做静态假数据原型。Element Plus 作为桌面后台组件基线，不再增加视觉选型问题。
4. 使用本机已有 MySQL `127.0.0.1:3307/lab_reservation` 与 Redis `127.0.0.1:6379`，不使用 H2 或本地锁冒充生产配置。测试单独创建 `lab_reservation_test`；任何清理策略必须校验数据库名，禁止清理开发库。
5. 密码只经环境变量传入，不读取、打印或写入项目文件。`local` 演示配置使用明确的非生产 JWT/内部服务口令；`prod` 缺失密钥时启动失败。
6. 模型 Key 当前不存在。AI 服务仍须真实实现并用假模型测试；无 Key 时返回 `AI_MODEL_NOT_CONFIGURED` 和普通表单入口，不伪造模型回答，不宣称真实平台联调通过。
7. 说明书中 48 位掩码以全天 00:00–24:00、每片 30 分钟为准，开放规则只限制可约范围。`SCHEDULABLE` 的请求窗口与最终分配时间分列保存。
8. 工位固定预约写 K 条正式分配并更新 K 个工位位图；整室预约写全部可用工位的正式分配记录但只更新整室位图，取消时按原粒度释放，避免双重占用。
9. 首版完成电脑端核心业务、三算法排期/发布、信用申诉、统计和 AI 模块；生产 HTTPS、备份恢复演练、微信绑定/扫码和真实模型联调不在本次验证范围内，页面不放假按钮。
10. 当前目录不是 Git 仓库。遵循用户未要求 Git 操作的约束，不初始化仓库、不提交文件；技能要求的规格文档仍保存，但省略提交步骤。

## 统一 API 契约

所有普通 JSON 响应为 `{ "code": 0, "message": "ok", "data": ... }`；业务错误使用非零 code 和对应 HTTP 状态。时间使用 ISO-8601，时区固定 `Asia/Shanghai`。

- `POST /api/auth/login`、`GET /api/auth/me`：BCrypt 校验，JWT 仅含用户 ID、角色和过期时间；每次请求复核账号仍有效。
- `GET /api/labs`、`GET /api/labs/{labId}/availability?date=YYYY-MM-DD`、`GET /api/labs/{labId}/rules`：返回实验室、48 片占用、工位状态和有效规则。
- `POST /api/reservations`：FIXED 输入 `labId,date,startTime,endTime,reservationMode,seatCount,purpose,preferences`；SCHEDULABLE 输入 `date,windowStart,windowEnd,durationMinutes,reservationMode,seatCount,purpose,preferences`，可选实验室集合。
- `POST /api/reservations/batches`：教师提交同一实验室多个不重叠整室时段，整批原子生效。
- `GET /api/reservations/my`、`GET /api/reservations?labId=&date=&status=`：本人或只读管理查询；`POST /api/reservations/{id}/cancel` 只允许本人按规则取消。
- `POST /api/checkin/terminal/session` 设置 HttpOnly 终端 Cookie；`POST /api/checkin/terminal`、`POST /api/checkin/terminal/select` 只使用该 Cookie，不签发学生 Web 会话。
- `POST /api/checkin/{id}/checkout`：本人签退，仅释放当前之后完整未用时间片。
- `GET /api/credit/me`、`GET /api/credit/violations`、`POST /api/appeals`；系统管理员用 `GET /api/admin/appeals`、`POST /api/admin/appeals/{id}/review`。
- `GET /api/schedules/tasks/{id}`、`GET /api/schedules/batches/{batchNo}`：任务、候选结果、主结果和指标只读查询；定时 Worker 负责运行与发布。
- `POST /api/experiments/run`、`GET /api/experiments/{batchNo}`：仅系统管理员，用合成快照做对照实验，不占生产资源。
- `GET /api/statistics/dashboard`、`GET /api/statistics/heatmap`、`GET /api/statistics/reservations.csv`：全部来自持久化事实，空数据返回零/空序列。
- `/api/admin/**` 仅系统管理员；实验室管理员只有 GET 查询权限，服务端必须拒绝其所有写请求。
- AI 内部接口：`GET /api/internal/auth/verify`、`GET /api/internal/rules`、`GET /api/internal/availability`、`GET /api/internal/users/{userId}/reservations`。全部要求内部服务凭据；用户 ID 只来自已验证上下文。
- AI 外部接口：`POST /api/ai/chat/invoke`、`POST /api/ai/chat/stream`、`GET /api/ai/chat/history/{threadId}`、`GET /api/ai/health`。SSE 客户端使用支持 POST 的 `fetch` 流读取，不使用 EventSource。

核心实现签名与边界：

```java
public record TimeSlotMask(int startSlot, int endSlot, long value) {
    public static TimeSlotMask between(LocalTime start, LocalTime end) {
        if (start.getSecond() != 0 || end.getSecond() != 0 ||
            start.getNano() != 0 || end.getNano() != 0 ||
            start.getMinute() % 30 != 0 || end.getMinute() % 30 != 0) {
            throw new IllegalArgumentException("invalid time range");
        }
        int from = start.getHour() * 2 + start.getMinute() / 30;
        int to = end.equals(LocalTime.MIDNIGHT) ? 48 : end.getHour() * 2 + end.getMinute() / 30;
        int length = to - from;
        if (length < 1 || length > 8) throw new IllegalArgumentException("invalid duration");
        return new TimeSlotMask(from, to, ((1L << length) - 1) << from);
    }
}
```

实现时把“24:00”作为显式 DTO 输入处理，避免 `LocalTime.MIDNIGHT` 被误判为当天开始；单元测试必须覆盖 23:30–24:00。
